# WiseWatt – AI Energy Consumption Predictor

WiseWatt is an AI-powered energy consumption prediction system that predicts appliance energy usage and provides optimized energy-saving recommendations.

## Features
- Energy consumption prediction
- Appliance-wise analysis
- Smart optimization suggestions
- Machine learning-based forecasting
- Flask web dashboard

## Technologies Used
- Python
- Flask
- Scikit-learn
- Pandas
- HTML/CSS
